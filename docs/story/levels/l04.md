# Level 4 — Read the name first

Location ID: `phone-shop` · Interaction: UpiPayment

Draft narrative; financial claims and language await sourced educator review.

## Hook

> Ravi: “The replacement charging cable is ready. Check the payment screen with me.”
> Ravi: “Who does it say you're paying?”

## Situation

Mina practises a fictional UPI payment for a replacement charging cable at Ravi's counter. The mock phone displays a payee, amount and payment direction. The player checks these before approval, using demo details only. The cable is practice context, not a required possession.

The micro-lesson contrasts sending with receiving and shows how a collect request asks for a payment. Ravi never asks Mina to reveal a PIN.

## Trap or misconception

“A familiar-looking name is enough,” or “a PIN prompt is needed whenever money moves.” A subtle payee mismatch needs checking. A UPI PIN authorises paying; receiving money does not require entering it. Exact guidance belongs in sourced level content.

## Consequence

The preview reveals that a similar name would send the fictional amount to the wrong payee. Pausing lets Mina verify the intended recipient and amount. A supposed incoming refund that requests a PIN is shown as an unsafe payment request, not a successful refund.

## Transfer twist

Two variants change payee and amount; one has a subtle name mismatch. Include a receiving-money prompt so the player checks direction as well as spelling. Every identifier remains an obvious demo placeholder.

## Scripted realistic mistake path

For the ordinary 2-star script, Mina marks the mismatched payee as correct in the checking step, before any authorisation. Ravi says, “Read the whole name; these are different recipients.” The player corrects the check, verifies amount and direction, then completes the transfer safely. Explain: recognition is not verification.

Sharing a PIN/OTP or authorising fraud is a separate critical path: unresolved earns 0 stars; corrected caps that attempt at 1. Never use it for the 2-star script. Clean replay can earn 3; best improves without erasing the first attempt.
